# Prediksi Konsentrasi PM2.5 Berbasis Data Kualitas Udara Dinamis dengan Continual Learning

## Tujuan Proyek
Mengambil data kualitas udara secara dinamis dari OpenAQ, mengolah data tersebut, menggunakan Random Forest Regressor untuk memprediksi konsentrasi PM2.5 pada periode berikutnya, kemudian melakukan monitoring dan retraining apabila terjadi data drift atau penurunan performa model.

## Struktur Direktori
data/       → penyimpanan data
models/     → penyimpanan model
notebooks/  → eksperimen dan analisis
src/        → kode utama pipeline
config/     → konfigurasi proyek
